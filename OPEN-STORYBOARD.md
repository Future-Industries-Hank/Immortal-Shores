# Open the art storyboard (no 404)

## Preferred

```bash
npm run dev
```

Then open:

**http://127.0.0.1:5173/storyboard/**

## Alternate

```bash
npm run storyboard
```

Then open:

**http://127.0.0.1:8765/ART-STORYBOARD-REVIEW.html**

(from repo root)

## Do not use

| URL | Result |
|---|---|
| `http://127.0.0.1:5173/ART-STORYBOARD-REVIEW.html` | 404 |
| `http://127.0.0.1:5173/docs/visual-inspiration/...` | 404 |
